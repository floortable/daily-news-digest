# 公開前の独立編集監査

監査対象は `generated/media/YYYY-MM-DD/editorial-audit-bundle.json` とする。生成担当の評価、Museレビュー、作業ログは読まず、完成物だけから独立して判定する。

## 全記事の一巡

`outlines` 全件で、出来事の主体・対象・変化・結果が概要の冒頭にあり、タイトルだけの言い換えになっていないか確認する。初見では役割が分からない組織・製品・略語、母数や比較対象のない数字、実質的更新のない再掲、別記事との重複、具体情報を増やさない留保や編集手順文を指摘する。

## 全文精査

`fullArticles` と `narration` だけを全文精査する。概要、解説、詳細欄、注目理由、台本が同じ内容を言い換えていないか、各欄が新しい理解を増やすか、結論より先に背景や専門語を並べていないかを確認する。Top 5では基礎説明、なぜ今起きたか、反証または別解釈、具体的な見通しが記事固有の根拠を伴うか確認する。

台本は、③で一括して書かれた一つの流れとして読む。①の裏付けが台本の事実へ反映され、冒頭で述べた中核事実を受けて次の情報へ進んでいるか、反響が簡潔な形で一回だけ置かれているか、②の調査材料が新しい具体情報として使われているかを確認する。あわせて、自然な敬体、役割が多くても紹介・解説・追加視点の3つ以内、唐突でない話者交代、読み上げる価値のある情報、英字名の登録済み読み、国名の日常的な呼び方を確認する。

## 役割と出力

これは公開可否を決める監査ではなく、主担当が公開前に直すための独立編集レビューである。合否や公開停止を宣言しない。問題がなければ「指摘なし」、問題があれば重要度（中心事実／内容改善／表現）、記事ID、該当欄、短い引用、判断根拠、最小修正案を1件1行で示す。記事本文、台本、ログを再掲しない。新しい候補探索は行わず、中心的主張を覆し得る疑いだけ一次資料で確認する。指摘後の再レビューは行わない。
