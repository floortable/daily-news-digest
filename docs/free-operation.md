# 無料運用ポリシー

## 必須条件

- GitHub Freeの公開リポジトリを使用する。
- 配信はGitHub Pagesの既定ドメインを使用する。
- CI/CDはGitHubホストの標準 `ubuntu-latest` ランナーだけを使用する。
- 有料プラン、有料API、有料またはセルフホストランナー、独自ドメインを使用しない。
- 無料枠の終了、超過、仕様変更が判明した場合は処理を停止し、有料サービスへ自動移行しない。
- 認証情報を追加する前に、サービスが恒久的な無料運用条件を満たすか人が確認する。

公開リポジトリの標準GitHub ActionsランナーとGitHub Pagesは、GitHubの現行条件で追加課金なしの構成として選択している。GitHub側の利用規約や上限は変更され得るため、定期的に公式Billingドキュメントを確認する。

## 無料では保証できない機能

品質を保証した生成AIによる毎日の要約・選定を、無人かつ無期限に無料で提供する外部サービスは前提にできない。GitHub Actions自体は無料でも、OpenAIなどの推論APIは別途課金となるため使用しない。

無料の代替案は次の順で扱う。

1. 現在の手動JSON投入を維持する。最も確実で、サイト・検索・RSS・公開はすべて無料で動作する。
2. はてな、Hacker News、各社公式RSSなど許諾された公開フィードから、タイトル・概要・URLを収集し、ルールベースで重複除去と順位付けを行う。転載範囲、アクセス制限、利用規約を個別に確認する。
3. 要約は配信元が提供する短い概要の参照、または人による独自要約とする。本文の無断転載はしない。
4. GitHub Actions上のローカルなオープンソースモデルは、標準ランナーの時間・メモリ・ダウンロード量で安定運用できると実測できた場合だけ検討する。失敗時は有料APIへ切り替えず、その日の自動生成を中止する。

無料AI API、プレビュー提供、クレジット付与は、上限や提供継続が保証されないため基盤要件には含めない。

## 変更時チェック

```sh
npm run check:free-tier
npm test
npm run build
```

`check:free-tier` は現在のworkflowについて、標準Ubuntuランナー以外、外部secret参照、代表的な課金AI設定を拒否する。GitHubのリポジトリ公開設定やPages設定はコードから検証できないため、GitHub Settingsでも確認する。
