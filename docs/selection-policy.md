# 記事選定ポリシー

このサイトの目的は、編集者の専門分野を深掘りすることだけではなく、国内外で実際に話題になっている出来事を横断し、普段の守備範囲外に出会える30記事を日本語で毎日届けることである。国や地域を先に割り当てず、内容の面白さ、重要性、話題性、分野の広がりで選ぶ。ニュース媒体だけでなく、Reddit、Hacker News、4chan、はてなブックマーク、Togetterなどのソーシャル上で関心が広がった題材も発見対象にする。

人気順をそのまま転載せず、人気指標を発見の入口として使う。掲載内容の正確性、出典、日付、権利は、人気とは別に確認する。

## 毎日の基本構成

原則として1日30記事とし、次の入口をすべて使う。

| 発見経路 | 目安 | 役割 |
| --- | ---: | --- |
| Hacker News | 4〜8件 | 技術に限定せず、科学、ビジネス、教育、文化などを拾う |
| はてなブックマーク | 4〜8件 | 日本語圏で共有・議論されている社会、生活、文化、技術などを拾う |
| ソーシャル発見 | 4〜8件 | Reddit、4chan、Lobsters、Bluesky、Mastodon、Togetterなどから、生活、文化、趣味、地域、人物、ネット文化を拾う |
| 横断媒体 | 3〜6件 | GIGAZINEなどから、分野をまたぐ話題や元記事への入口を得る |
| 一般報道・一次情報 | 8〜12件 | 大きなニュースの確認と、ランキングだけでは拾いにくい重要事項を補う |

同じ記事が複数経路に現れた場合は1記事として数え、該当する経路をすべて記録する。発見経路は出典ではない。必ず原文、公式発表、信頼できる報道などの個別ページを確認する。

## 地域の扱い

日本、海外、特定地域の件数枠は設けない。地域ではなく内容で判断し、その結果として海外記事または日本の記事が多くなることは許容する。ただし、一つの国や英語圏だけへの偶発的な集中が、収集元の偏りによるものではないかを最終レビューで確認する。日本語記事が見つからないことを不採用理由にせず、原文を確認して日本語で要約する。紹介記事を入口にした場合は、可能な限り元記事、論文、公式発表まで遡る。

## ソーシャル発見の扱い

- Togetter、Reddit、4chanなどは「何が話題か」を見つける入口であり、投稿内容だけを事実確認の根拠にしない。
- Togetterでは、まとめられた投稿の文脈、元投稿、恣意的な抜粋の可能性を確認する。
- Redditでは、サブレディット名、投稿日時、スコア、コメント数、元リンクを確認し、再投稿や同一題材の重複を除く。
- 4chanでは、板名、スレッド確認時刻、返信数を記録できる場合だけ候補化する。匿名の主張、リーク、個人特定情報は、独立した一次資料または信頼できる報道で裏付けられない限り掲載しない。
- 投稿やスレッドが削除される可能性を前提とし、削除済みコンテンツの転載、アーカイブ回避、アクセス制限の回避は行わない。
- 個人晒し、住所・連絡先などの個人情報、差別扇動、嫌がらせ、違法性の疑われる画像、性的搾取、残虐画像は採用しない。
- ミーム、創作、ジョーク、風刺は、事実報道と混同しない形でネット文化や反応として扱う。
- ソーシャル上の反応を一般世論と表現しない。「特定コミュニティで話題」と範囲を限定する。

## 分野のバランス

30記事全体では次を目安とする。日によって該当ニュースが乏しい場合は無理に埋めず、編集メモに理由を残す。

- 社会・政治・国際: 4〜6件
- 経済・仕事・ビジネス: 3〜5件
- テクノロジー: 3〜5件
- 科学・医療・環境: 3〜5件
- 暮らし・消費・教育: 3〜5件
- 文化・エンタメ・趣味: 3〜5件
- スポーツ: 1〜3件
- 地域・人物・意外性のある話題: 2〜4件
- VCF・VMware・競合: 1〜2件

テクノロジー、セキュリティ、VCF・VMware・競合を合計して12件を超えない。専門枠は重要だが、全体の中心にはしない。

同一媒体は原則4件まで、同一組織の公式発表は原則3件までとする。同じ出来事を扱う記事は、独自情報や明確に異なる視点がない限り重複掲載しない。

## Top 5の選び方

Top 5は「最も硬い5件」でも「人気指標の上位5件」でもない。次の観点を組み合わせ、その日の全体像が5件で伝わるように選ぶ。

1. 多くの人の生活、安全、権利に関係するもの
2. 国内外の大きな変化を理解するために必要なもの
3. はてなブックマーク、Hacker News、Togetter、Redditなどで実際に議論が広がったもの
4. 専門外でも知る価値がある科学、文化、教育、スポーツ、地域などのもの
5. 驚き、発見、人間味、前向きな変化のあるもの

Top 5は4分野以上、4媒体以上から選ぶ。テクノロジー・セキュリティ・VCF系は合計2件まで、政府機関などの公式発表は合計2件までとする。Hacker News、はてなブックマーク、またはソーシャル発見由来を合計2件以上含め、文化、暮らし、科学、スポーツ、地域・人物のいずれかから1件以上含める。国や地域を理由にTop 5へ入れたり外したりしない。4chan由来の記事をTop 5に入れる場合は、一次資料または複数の信頼できる報道による裏付けを必須とする。

## 人気指標の扱い

- はてなブックマーク数、Hacker Newsのポイント数・コメント数は、確認した時刻とともに記録する。
- Togetterの閲覧数、Redditのスコア・コメント数、4chanの返信数など、取得可能なソーシャル指標も確認時刻とともに記録する。
- 数値は変動するため、順位の絶対的な根拠にはしない。
- 扇情的、差別的、誤情報の疑いがある記事は、人気が高くても採用しない。
- 意見記事は事実報道と区別し、反対意見や一次資料を確認する。
- Hacker Newsでは技術記事だけに偏らず、科学、教育、経済、公共政策、歴史、文化、個人プロジェクトも候補にする。
- はてなブックマークでは政治・炎上だけに偏らず、生活、仕事、創作、趣味、地域の話題も候補にする。
- GIGAZINEなどの横断媒体は幅を広げる入口に使い、海外記事では元の報道、論文、公式発表まで遡る。

## 選定手順

1. 前日から当日朝までを基本対象期間として、Hacker News、はてなブックマーク、Reddit、4chan、Lobsters、Togetter、GIGAZINE、一般報道・一次情報から並行して候補を集める。
2. URL、公開日、出典、情報種別、人気指標を確認する。未来日付、架空URL、検索結果だけの情報は採用しない。
3. 重複を除き、分野、媒体、地域、硬軟、専門内外の偏りを確認する。
4. 30記事を選び、最後にTop 5を別工程で選ぶ。
5. 独自タイトル、短い独自要約、80文字以上のコメントを作成し、編集・権利ポリシーに従って確認する。
6. データ検証、テスト、ビルド後に公開する。

## 採用しない選び方

- URLを検証しやすいという理由だけで官公庁発表を大量採用する
- 一つの媒体からまとめて取得して件数を満たす
- 編集者の専門分野だけで30件の大半を構成する
- カテゴリ名だけを「生活・文化」にして、実質的な硬さや偏りを隠す
- 人気指標だけで真偽や重要性を判断する
- 架空の記事、将来の出来事、確認できない数値を実在ニュースとして扱う
