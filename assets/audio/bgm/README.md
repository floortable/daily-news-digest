# Top 5 BGM library

このディレクトリの音源は、Sunoの有料プランで制作したDaily News Digest専用の
オリジナルBGMです。

2026-10-26に6曲を追加し、現在は12曲を登録しています。曲名、収録時間、原本の
SHA-256は `tracks.json` を正本として管理します。

権利確認日: 2026-10-26。各曲は有料プラン契約中にユーザー自身が生成し、Sunoの正規の
ダウンロード機能で取得したものです。他者の曲のRemix、第三者の歌詞、権利未確認の
アップロード音源は含めません。生成時とダウンロード時の有料プラン利用記録は、
リポジトリ外で保管します。

## 選曲

`config/bgm-selection.json` で記事テーマごとの候補曲を絞り、その候補内で日付と記事を種に
選曲します。同じテーマでも日によって曲が変わり、同じ日を再生成した場合は同じ曲になります。
Top 5ではテーマ適合を最優先し、その範囲で可能な限り曲を重複させません。記事間では前の曲を
フェードアウトし、ジングルの後、次のトピック開始時に新しい曲をフェードインします。
各トピックが曲の収録時間を超える場合はループします。
