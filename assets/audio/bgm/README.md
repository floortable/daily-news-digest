# Top 5 BGM library

このディレクトリの音源は、リポジトリ所有者がSunoの有料プラン加入中に生成し、
Daily News Digestの動画・音声配信に使用するため提供したものです。

- 権利根拠: 生成者本人による「有料プラン加入中に生成した」との申告
- 利用目的: Daily News DigestのTop 5動画・音声・関連する告知

- 音源そのものについて、第三者への複製、再配布、改変、再利用の許諾は行いません。
- Sunoの規約変更や権利上の申し立てがあった場合は、公開と新規生成を停止して確認します。

原本はM4Aコンテナ内のOpus音声です。公開生成時に互換性の高いAACへ変換し、
読み上げを妨げない音量へ調整します。原本を直接Web配信する用途では使用しません。

## 選曲

日付から決定的に1曲を選び、同じ日を再生成しても選曲が変わらないようにします。
収録時間を超える場合はループし、読み上げ終了時にフェードアウトします。
